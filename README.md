# Afterglow — Festival of India

### An Immersive Indian Cultural Festival Experience

**Afterglow** is an interactive festival website designed to celebrate the rich cultural heritage, traditions, art, music, dance, and cuisine of India.

The website invites visitors to explore the beauty and diversity of Indian culture through a visually engaging digital experience, combining immersive 3D animations with modern web design.

## About the Project

Afterglow was developed as a university web development project using a customized open-source website template.

The goal is to transform an existing creative website into an engaging cultural festival platform while maintaining its original interactive elements and introducing a new visual identity, content, and navigation structure.

The website provides visitors with an introduction to Indian culture and highlights the different experiences that a cultural festival can offer.

## Features

- **Interactive 3D Environment:** An animated river scene featuring floating lanterns, realistic reflections, and atmospheric lighting.
- **Festival Highlights:** Interactive cards showcasing Indian music, dance, food, art, and cultural traditions.
- **Cultural Experiences:** Dedicated sections introducing visitors to different aspects of Indian heritage.
- **Smooth Navigation:** Scroll-based transitions through multiple sections of the website.
- **Free Drift Mode:** Allows visitors to explore the 3D environment interactively.
- **Ambient Sound:** Background audio and interactive sound effects.
- **Responsive Design:** Layouts adapted for desktop and mobile screens.
- **Contact Section:** A demonstration form for festival inquiries.

## Installation and Setup

To run the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/afterglow-festival.git
```

**2. Navigate to the project directory**

```bash
cd afterglow-festival
```

**3. Run the website**

Open `index.html` using a local development server, such as the Live Server extension in Visual Studio Code.

No additional package installation or build process is required.

## Deployment

The website can be hosted using GitHub Pages.

1. Open the GitHub repository.
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Save the settings.

Once deployed, the website will be available at:

`https://YOUR-USERNAME.github.io/afterglow-festival/`
